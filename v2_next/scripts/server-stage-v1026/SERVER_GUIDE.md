# v1.0.26 전송·정적 사전점검

사내 개발·검증용 미서명 파일입니다. 설치 준비 완료 또는 정식 운영 승인본이 아닙니다.
외부·고객·협력사·공개 배포 금지. 책임 개발자가 통제하는 지정 서버에만 전달합니다.

## 서버로 옮길 파일

새로 발행된 `v1026-server-stage-ready-*.zip`와 같은 이름의 `.zip.sha256.txt` 두 개만
`C:\Users\user\Desktop\SmartFactory`로 옮깁니다. 압축을 수동으로 풀거나 installer,
Canary, 예전 버전 CMD를 직접 실행하지 마십시오.

빌드 호스트의 `START_V1026_STAGE.txt` 또는 채팅으로 별도 전달된 동일 명령을 관리자
64-bit Windows PowerShell 5.1에 붙여 넣습니다. 코드 블록 안의 명령만 복사합니다.
ZIP 안의 sidecar를 스스로 신뢰 기준으로 삼지 않으며, ZIP 밖의 명령에 고정된
ZIP/helper/manifest 길이·SHA-256 기대값을 확인합니다.

## 자동 안내 단계

1. 외부 고정 해시와 32개 파일의 경로·크기·내용 검사.
2. 현재 v1.0.25의 health/config와 프로세스 경로·시작 시각 읽기.
3. 새 `C:\ProgramData\SFL26S-<무작위 값>` 보호 폴더 생성 및 전항목 재검증.
4. 정확한 설치 후보 14개와 실행 차단된 Canary 15개 정적 검증.
5. 실행본·설정이 바뀌지 않았는지 확인하고 별도 결과 JSON 및 SHA 생성.
6. 결과 경로 출력. 전체 출력을 전달합니다. 마지막 YES 질문은 없습니다.

현재 앱과 정상 SPOT 화면을 그대로 둡니다. 제품번호·금형번호 입력, 리셋, 오류 비우기,
앱 종료 또는 재시작을 요청하지 않습니다. GET은 로컬 health/config뿐이며 카메라
image endpoint를 호출하거나 새 packet capture/관측을 시작하지 않습니다.
로컬 요청을 받은 앱이 통상적인 자체 로그를 남길 수는 있습니다.

## 중단 조건과 원본 보존

관리자 native PS 5.1이 아니거나 파일/해시/ACL/현재 버전/실행본이 다르면 HOLD입니다.
설정 파일은 앱의 쓰기·교체를 허용한 짧은 공유 읽기를 사용하며, 전후마다 경로를 새로
열어 비교합니다. 설정이 바뀌면 HOLD입니다. 바뀌었다가 동일한 바이트로 돌아오는 모든
중간 변경을 감지하는 지속 감시는 아닙니다. 점검 중에는 설정을 그대로 두십시오.
파일을 덮어쓰거나 실패 폴더를 자동 삭제하지 않습니다. 재실행하면 별도 증거가 되므로
HOLD 출력부터 검토하며 자동 반복 실행하지 않습니다.

서버에 이미 있는 아래 v1.0.25 복구 후보를 읽기 검증합니다. 없으면 HOLD이며,
임의 대체 EXE를 사용하지 않습니다.

`C:\ProgramData\SFL-76B317D0A2901C6EFC649404211C8109\SmartFactoryLogger_v1.0.25_a203baf_unsigned_internal_20260909T012500Z\smart-factory-logger-v2 Setup 1.0.25.exe`

해시 일치는 복구 가능 판정이 아닙니다. 현재 설정·데이터 보존/호환성, 현재 오류,
시험 시간대·검증 기간·중단/복구 조건은 설치 전에 별도로 검토해야 합니다.
이번 도우미는 현재 설치 트리 전수검사, 데이터 백업 및 복구 시험을 하지 않습니다.

## 기록 해석

성공 결과는 `V1026_TRANSFER_STAGED_RUNTIME_RECORDED_NOT_INSTALL_READY`입니다.
이미지 상태 스냅샷에 오류/누락 값이 있어도 정적 파일 검증 성공과 구분해 그대로 기록합니다.
현재 건강 상태를 승인하지 않으며 `current_health_approved=false`입니다.
전체 운영 점검이나 영상 갱신 관측 PASS로 사용하면 안 됩니다.

제품 commit은 `d7a1b20f96711fb07fc7add0867e79ee36506fce`, Canary 도구 master는
`c03f7c76ff6e75bfe330275ac0fa01326f357261`입니다. 새 staging 도우미는 별도 해시로
고정한 로컬 준비본이며 아직 커밋되지 않았습니다. 설치 후보와 Canary 안의 과거
준비 상태 문구는 원본 그대로 보존하고 새 전송 manifest/결과로 출처를 보완합니다.
v1.0.25의 과거 15/120분 PASS를 v1.0.26 통과로 재사용하지 않습니다.

이번 단계로 설치·정상 종료·재시작·15/120분 관측·자동 롤백·운영 승격은 승인되지 않습니다.
강조 애니메이션은 기존 제품 기능 그대로 유지되며 현장 체감 개선은 설치 후 별도 검증합니다.
