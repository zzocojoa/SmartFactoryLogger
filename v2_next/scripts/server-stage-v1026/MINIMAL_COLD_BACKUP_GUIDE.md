# v1.0.25 최소 콜드 백업 실행 도우미

실행 승인을 받은 뒤에만 `-Execute`로 사용한다. 도우미는 현재 사전점검에서 확인한
v1.0.25 프로세스 인스턴스·설정·복구 설치본을 다시 확인하고, 토큰 입력 뒤 작업자가
SmartFactory 창을 X로 정상 종료하도록 안내한다. 강제 종료·자동 재시작·설치는 없다.

포함 범위는 Electron 프로필 전체, layouts 전체, 사전점검에서 존재가 확인된 여덟 개의
고정 설정/작업자/상태 파일이다. `SmartFactoryLogger\logs`의 CSV·이미지·fact·진단 로그,
snapshots와 설치 프로그램 폴더는 제외한다. 따라서 누적 업무 데이터를 복구하는 백업이 아니다.

새 결과는 `C:\ProgramData\SFLOps\backups\v1025-min-<id>`에만 만든다. 관리자와 SYSTEM만
접근 가능한 새 폴더를 사용하며 기존 자료를 덮어쓰거나 삭제하지 않는다. 정상 종료 후 원본을
백업하고, 별도 restore 트리에 다시 복사하여 파일별 SHA-256·구성·원본 재해시를 검증한다.

완료 후에도 앱은 정지 상태다. result.json과 해시, 전체 콘솔 출력을 전달한 뒤 v1.0.26
설치 판단을 기다린다. HOLD가 나오면 자동 재실행·정리·재시작·설치·롤백을 하지 않는다.
