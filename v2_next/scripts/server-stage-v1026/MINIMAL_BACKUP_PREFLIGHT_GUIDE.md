# v1.0.25 최소 백업 읽기 전용 사전점검

이 단계는 백업을 만들지 않는다. 실행 중인 v1.0.25의 설정/UI 상태와 Electron 프로필을
메타데이터로만 열거하고, 새 정책 경로 `C:\ProgramData\SFLOps\backups\<id>`를 사용할 수
있는지 확인한다. 앱 종료, 파일 복사, 설치, 재시작, 롤백, 이미지 요청은 수행하지 않는다.

## 포함 예정 범위

- `SmartFactoryLogger`의 고정 설정·레이아웃·작업자 메타데이터·상태 파일
- `SmartFactoryLogger\layouts` 전체(존재하는 경우)
- Electron 사용자 프로필 `smart-factory-logger-v2` 전체

## 의도적으로 제외하는 범위

- `SmartFactoryLogger\logs`의 CSV, 이미지, fact, 진단 로그
- `SmartFactoryLogger\snapshots`
- 설치 프로그램 폴더 전체

따라서 최소 백업은 설정·UI/작업자 상태 복구용이다. 업그레이드나 이후 런타임이 누적
CSV/이미지/fact를 손상시키는 상황은 복구하지 못한다. 설치 폴더는 검증된 v1.0.25
복구 설치본을 사용한다는 전제이며, 복구 설치본 자체의 운영 적합성은 별도 검토 대상이다.

사전점검 PASS 뒤에 별도의 해시 결합 실행 도우미를 만든다. 그 도우미는 현재 런타임을
실행 시점에 다시 확인하고, 작업자가 앱을 정상 종료한 다음 새 백업 폴더에만 복사하며,
원본/백업/복원 시험본을 재해시해야 한다. 기존 `SFL26B-*` 도우미나 결과는 수정·이동하지 않는다.

HOLD가 나오면 자동 재시도·정리·설치·재시작을 하지 말고 전체 출력을 전달한다.

정정본 `r2`는 `$env:APPDATA`를 사용자 Roaming 루트와 비교한다. 최초 배포본은 제품
하위 폴더와 잘못 비교해 실제 점검 전에 HOLD됐으며, 재실행하지 않는다.
