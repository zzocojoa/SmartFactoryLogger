# v1.0.26 설치·30초 사후 점검

이 패키지는 완료된 v1.0.26 보호 스테이징과 완료된 v1.0.25 최소 콜드 백업을
정확한 경로와 SHA-256으로 다시 결합한 뒤에만 설치를 시작한다.

## 실행 전 상태

- SmartFactory는 최소 백업 완료 후 중지된 상태여야 한다.
- 관리자 권한 64비트 Windows PowerShell 5.1을 사용한다.
- 별도로 제공된 외부 고정 launcher로 ZIP과 helper를 검증한다.
- 설치 승인 전까지 installer, 앱 시작, Canary 관측은 실행되지 않는다.

## 작업자 입력

1. 범위·백업·스테이징 검증이 통과하면 `INSTALL V1.0.26`을 입력한다.
2. 대화형 installer 창이 나타나면 정상적인 한 번 클릭 설치를 완료한다.
3. v1.0.26이 자동 시작되면 정상 SPOT 화면을 열고 영상 갱신을 확인한다.
4. 실제로 갱신 중일 때만 `READY`를 입력한다.

## 보장 범위와 제한

도우미는 표준 사용자 installer 프로세스를 관측하고, 설치 후 버전·커밋,
1,646개 설치 파일, 생성된 uninstaller, config 무변경과 30초 SPOT 로컬 카운터를
검증한다. 강제 종료, 자동 재시도, 자동 롤백, 정리, 15분/120분 관측은 하지 않는다.

최소 백업은 CSV, 이미지, fact/진단 로그, snapshots, 기존 설치 폴더를 포함하지 않는다.
따라서 해당 자료를 복구하는 전체 백업으로 취급하면 안 된다. HOLD가 발생하면 현재
상태와 전체 출력을 보존하고 재실행하거나 v1.0.25 installer를 임의 실행하지 않는다.
