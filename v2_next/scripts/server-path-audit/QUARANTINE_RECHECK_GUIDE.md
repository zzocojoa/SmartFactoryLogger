# 구버전 격리 자료 읽기 전용 대조

## 범위

사용자가 제공한 2026-08-13 격리 manifest와 정정 검증 기록에 결합된 검사다.
서버의 `C:\Users\user\Desktop\SmartFactory_Archive\pre_v1020_quarantine_20260813_092302`
아래 136개 최상위 항목, 558개 파일, 1,077,165,719바이트를 대상으로 한다.
첨부 JSON 3개와 각 sidecar가 일치하고, R1_1의 manifest/최초 receipt 해시 결합도 확인했다.
이것은 첨부 자료 내부의 무결성 확인이지 발행자 인증 또는 현재 서버 파일 검증은 아니다.

최초 PASS는 최상위 항목 검증을 측정하지 못한 구문 오류로 대체됐다. R1_1의 PASS는
당시 이동 검증 기록이다. 당시 승인되지 않은 영구 삭제/서버 설치를 이번 검사도 수행하지 않는다.
manifest에는 `backup_before_install`의 구버전 설정·로그 12개 파일(239,100,401바이트)이
포함된다. 현재 v1.0.25 데이터 전체 백업으로 해석하지 않는다.

## 실행 방법

서버로 전달할 파일은 `read-quarantine-pre-v1020.ps1`와 `.ps1.sha256.txt` 두 개뿐이다.
기존 Desktop\SmartFactory 전송 경로는 읽기 원본으로만 사용한다. 대화에서 제시된 외부
SHA-256/크기를 검증하는 실행 명령을 관리자 native x64 Windows PowerShell 5.1에서 사용한다.
서버용 main을 개발 PC에서 실행하지 않는다. 독립 증거 검증 함수 테스트만 로컬에서 실행한다.

새 ZIP, 로그 파일, 폴더를 생성하지 않는다. 이후 저장이 필요한 도우미의 고정 부모는
`C:\ProgramData\SFLOps`이며 이번에 그 폴더를 생성/이관하지 않는다.
과거 경로에는 240자를 넘는 파일 14개(최대 257자)가 있어 읽기 검사만 259자까지 허용한다.
기존 원본/manifest를 짧은 경로로 수정하거나 이동하지 않는다.

## 단계와 부하

1. 외부에 고정된 세 JSON의 크기·SHA-256과 sidecar 확인.
2. 격리 폴더를 제한적으로 재귀 열거. reparse는 따라가지 않고 오류로 기록.
3. 558개 파일 약 1.08GB를 읽어 해시 대조. 50개마다 진행 출력. 종료 시까지 읽기 잠금 유지.
4. 로컬 프로세스/서비스/시작 항목/예약 작업 및 제한된 바로가기·도우미 텍스트의 참조 검색.
5. 다시 열거해 내용 목록·크기·시각 변화 확인 후 콘솔 JSON 출력.

앱 종료·재시작·설치·네트워크/SPOT/API 요청·관측·삭제·이동은 하지 않는다.
해시 I/O 및 잠금은 약간의 부하를 유발하고, 검사 중 격리 파일 변경/삭제를 막을 수 있다.
앱 정상 실행은 유지한다. 해당 폴더의 다른 작업은 검사 중 하지 않는다.
불일치나 접근 실패 시 원본을 고쳐 맞추거나 자동 재실행하지 말고 출력을 전달한다.

## 결과 해석

- `QUARANTINE_BYTES_MATCH_REVIEW_ONLY`: 고정 manifest 파일의 현재 바이트와 열거 결과가 일치.
  참조 부재, 백업 적합성, 보존기간, 삭제 승인을 의미하지 않는다.
- `QUARANTINE_RECHECK_HOLD`: 누락/차이/추가/미기술 디렉터리/불완전 열거/전후 변화 등을 검토.
- `deletion_approved=false`는 모든 결과에서 유지한다. 서버 삭제 명령은 포함하지 않는다.

시스템 응답은 ID/필드 이름/일치한 과거 파일명만 출력한다. 명령줄, shortcut 인수,
문서 내용, 설정 값, 토큰/비밀번호를 출력하지 않는다. 파일명/로컬 경로 자체는 사내
메타데이터이므로 공개 게시하지 않는다.

## 검색 한계

바탕화면 바로가기와 Desktop\SmartFactory 텍스트는 직계 파일만, Start Menu는 깊이 5,
기존 ProgramData의 SFL 6개 루트 텍스트는 깊이 3까지다. 루트별 3,000항목·15초,
선택 텍스트 확장자·파일당 1MiB·총 32MiB·120초 한도를 기록한다. 비실행 task action,
null 명령 필드, 접근/디코딩 오류, 깊이/수량/시간/크기 제한, 초과 일치 수를 보고한다.
텍스트 일치는 실제 사용 증거가 아니며, 불일치는 미사용 증거가 아니다.
다른 사용자/드라이브, 임의 설정/env 경로, 인코딩/간접 참조, 모든 열린 핸들,
ZIP 내부 내용, 스케줄의 향후 실행 경로, 파일 보존기간은 검증하지 않는다.
manifest에 빈 디렉터리 목록은 없으므로 파일 목록으로 유도되지 않는 폴더는 검토 대상으로 남긴다.
시간 한도는 OS/COM 호출 사이에서 확인하며, 한 번 막힌 호출을 강제 중단하지 않는다.
읽기 잠금은 적대적인 부모 디렉터리 교체나 전체 파일시스템 스냅샷을 보장하지 않는다.

## 로컬 시험

`test-read-quarantine-pre-v1020.ps1`는 서버 main 없이 함수/AST를 시험한다.
Windows PowerShell 5.1.26100.9444에서 합성/업로드 metadata 검사 59개 및 기존 탐색
회귀 검사 17개를 통과했다. 독립 정적 코드 검토에서 차단 결함이 없었다.
`-EvidenceDirectory`를 주면 사용자가 개발 PC로 전달한 JSON 3개만 추가 검사하며,
그 안의 서버 경로를 열지 않는다. 프로세스/서비스/task는 mock 응답으로 시험한다.
실제 서버 558개 파일, COM 바로가기, 접근거부/reparse/동시 경로 교체 현장 시험은 별개다.
제품 코드·Canary·설치본을 수정하지 않아 앱 통합/설치/운영 시험은 수행하지 않는다.
복구/마이그레이션 작업은 없으며, 실패 시 원본 보존 후 결과 검토가 운영 대응이다.
