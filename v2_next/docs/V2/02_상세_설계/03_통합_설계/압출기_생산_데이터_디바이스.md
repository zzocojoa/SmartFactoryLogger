## 1. 개요

본 문서는 압출기(Extruder)의 생산 데이터 디바이스 정보를 V2 실데이터 연동 기준으로
정리한 레퍼런스 문서입니다. 원본 PDF의 표 구조를 기준으로 PLC 주소, 데이터 타입,
허용 범위, 읽기 권한, 표시 정책을 보존했습니다.

## 5. 구현 참고 사항

- 원본 표의 모든 데이터는 `Read` 권한으로 정의되어 있으므로, V2 연동에서는 기본적으로
  읽기 전용 데이터로 취급합니다.
- 속도, 압력, 위치 항목은 원본 비고 기준으로 표시 단계에서만 소수점 1자리 반올림 또는
  포맷팅을 적용합니다. 수집 원본값의 스케일링 여부는 별도 현장 검증이 필요합니다.
- 위치 항목의 상한 값은 원본에 기재되어 있지 않습니다. 알람/검증 범위로 사용하기 전에
  설비 사양 또는 현장 PLC 값을 기준으로 확정해야 합니다.
- `B` 주소와 `D` 주소의 의미 및 읽기 프로토콜 세부사항은 원본 PDF에 명시되어 있지
  않습니다. 기존 V1 드라이버 또는 현장 PLC 매뉴얼과 대조해야 합니다.
- 32 Bit Float 항목인 `버트 길이(mm)`는 16 Bit Decimal 항목과 다른 디코딩 경로가
  필요할 수 있습니다.
