백분위는 `sorted_values[ceil(p*n)-1]`(nearest rank)다. 비어 있는 표본·잘못된 시계·관찰
누락은 PASS가 아니다. 500/1,000/1,500ms와 200/500ms는 이하가 합격이고,
이미지 정지 2,000ms/온도 공백 3,000ms는 **같아도 불합격**이다.

화면은 서버 포함 물리 PC 4대·각 대시보드 1개가 실제 표시되는 기존 15분 관찰 방식으로
추가 계측한다. 각 PC 결과와 동시 조회 구간을 구분한다. 숨김/최소화/화면 잠김/화면 미확인은
계측 불완전이다. load·RAF만으로 물리 표시나 새 센서 프레임을 확정하지 않는다.
처음/끝 경계까지 정지 시간을 확인하고, 관찰 종료 직전 진행 요청은 제한된 후속 관찰로 정산한다.
센서 프레임 식별 근거가 부족하면 그 부분을 미확인으로 남긴다. 같은 픽셀은 정적인 장면일 수 있다.

온도 수신 시각은 CSV 행 생성 시각과 다르다. sentinel도 실제 응답 상태로 보존하고,
온도값이 바뀐 시점만 선택해 수신 간격을 계산하지 않는다. 같은 관측을 반복한 CSV 행을
새 측정으로 세지 않는다. 약 1초 수신을 모든 짧은 물리 변화/딥러닝 적합성의 증명으로 사용하지 않는다.

기존 15/120분 원본을 새 평가 파일에서 재평가한다. 원래 FAIL/INCOMPLETE는 수정하지 않는다.
